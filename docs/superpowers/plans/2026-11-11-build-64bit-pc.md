# Build 64-bit no PC — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Project-Veronica compila e roda como executável x86-64 no Windows com quadros idênticos aos do build 32-bit.

**Architecture:** Estruturas lidas do disco mantêm campos de 4 bytes (`ps2ptr_t`) convertidos por macros; estruturas de tempo de execução usam ponteiros nativos. Etapa 1a mantém a imagem em `0x30000000` (macros = cast); etapa 1b torna as macros relativas a uma base, para carga em qualquer endereço.

**Tech Stack:** C (gnu11), C++ (ImGui), CMake + Ninja, GCC mingw-w64 i686 e x86_64 (MSYS2 em `C:\msys64`), SDL3, OpenGL 3.3, Python 3, bash.

**Spec:** `docs/superpowers/specs/2026-11-11-build-64bit-pc-design.md`

## Global Constraints

- O build 32-bit do branch deve gerar quadros idênticos aos de `ref32` depois de cada tarefa que toque código.
- Mudanças na decompilação: submódulo `decomp`, branch `nx/64bit`, dentro de `#ifdef TARGET_PC` ou atrás das macros de `pc/include/pc_ptr.h`.
- Só GCC. Flags do jogo inalteradas (`-fsigned-char -fwrapv -fno-strict-aliasing -ffp-contract=off -msse2 -mfpmath=sse -fno-tree-vectorize -ftrivial-auto-var-init=zero`, `-mno-ms-bitfields`).
- Nada derivado da ISO entra no repositório. Dumps e builds ficam em `build*/` e `scratch/` (ignorados pelo git).
- ISO de teste: `C:\Users\geris\OneDrive\Área de Trabalho\[PS2] RE Code Veronica X (BR) (DUB).iso` (passada por `RECVX_ISO`).
- Commits locais no branch `nx/64bit`; nada de push.

## Review Focus

1. Sala fora do roteiro automático com modelo cujo campo do disco não foi convertido: deve funcionar; coberto pela sessão manual (Tarefa 7) e pelos `_Static_assert` de layout (Tarefa 3).
2. Ponteiro guardado em área de trabalho acessada por offset numérico (`EXP0_*`): auditoria na Tarefa 5, com lista em `docs/dev/64bit-audit.md`.
3. Save criado no build 32-bit carregado no 64-bit e vice-versa: teste na Tarefa 7.
4. Endereço host acima de 4 GB entrando num slot na etapa 1a: `S32` aborta com mensagem em build debug (Tarefa 3, `test_ptr`).
5. Endereço do scratchpad (`0x7000xxxx`) e aliases (`|0x20000000`, `|0x30000000`, `|0x80000000`) na etapa 1b: `test_ptr` cobre a ida e volta (Tarefa 8).
